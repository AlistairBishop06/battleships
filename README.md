# Battleships (Python Project)

## Overview
A Python-based implementation of the classic strategy game *Battleships*. This project includes a command-line player vs AI mode, as well as a web-based interface using Flask for ship placement and gameplay.

---

## Features Completed

### Core Application
- Initialise board  
- Create battleships  
- Place battleships  
- Attack system  
- Command-line input for attack coordinates  
- Simple game loop  

### Multi-player Constructs
- Player system  
- AI opponent  
- AI command-line game loop  

### Flask GUI
- Battleship placement page  
- Gameplay page  

### Optional Enhancements
- Difficulty levels  
- Improved AI:
  - Better ship placement  
  - Smarter guessing (targets adjacent squares after hits)
